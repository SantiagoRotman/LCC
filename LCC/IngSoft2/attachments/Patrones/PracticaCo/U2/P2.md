# Acceso a un canal de navegación

## Enunciado

Se trata de un software que deberá controlar el acceso de barcos a una exclusa que comunica el mar con un canal. El software puede controlar la llegada de embarcaciones desde ambos extremos, puede abrir y cerrar ambas puertas, puede encender y apagar bombas hidráulicas para llenar y vaciar la exclusa. Además hay sensores que reportan la profundidad de la exclusa y de los cursos de agua a ambos lados. Excepto los sensores que comunican la llegada de
embarcaciones, todo los demás no emiten señales sino que el sistema debe consultarlos.

Aplicar el patrón Command

## Documentación

| Pattern       | ComandosCanal |
|---------------|---------------|
| **based on**  | Command |
| **because**   | - Permite agregar nuevas operaciones de forma sencilla |
| **where**     | Command **is** Comando<br>ConcreteCommand **is** ComandoAbrirPuertaOeste<br>ConcreteCommand **is** ComandoAbrirPuertaEste<br>ConcreteCommand **is** ComandoCerrarPuertaOeste<br>ConcreteCommand **is** ComandoCerrarPuertaEste<br>ConcreteCommand **is** ComandoLlenar<br>ConcreteCommand **is** ComandoVaciar<br>ConcreteCommand **is** ComandoSensarProfundidad<br>ConcreteCommand **is** ComandoSensarCursoDeAgua<br>Invoker **is** Invocador<br>Client **is** Sistema<br>Receiver **is** ControlPuertas<br>Receiver **is** ControlBombasHidraulicas<br>Receiver **is** ControlSensoresDeProfundidad<br>Receiver **is** ControlSensoresDeCursoDeAgua<br>Execute() **is** ejecutar()<br>Action() **is** abrir()<br>Action() **is** cerrar()<br>Action() **is** llenar()<br>Action() **is** vaciar()<br>Action() **is** sensar()<br>Action() **is** sensar() |

## Módulos 2MIL

```
MODULE  Puerta
EXPORTS abrir()
        cerrar()
```

```
MODULE  BombaHidraulica
EXPORTS llenar()
        vaciar()
```

```
MODULE  SensorPasivo
EXPORTS sensar() : Int
```

```
MODULE  SensorActivo
EXPORTS inicializar(i *f)
```

```
MODULE  SensorProfundidad INHERITS FROM SensorPasivo
```

```
MODULE  SensorCursoDeAgua INHERITS FROM SensorPasivo
```

```
MODULE  SensorLlegadaEmbarcación INHERITS FROM SensorActivo
```

```
MODULE  ControlPuertas
IMPORTS Puerta
EXPORTS abrir(i Puerta)
        cerrar(i Puerta)
        agregar(i Puerta)
        eliminar(i Puerta)
```

```
MODULE  ControlBombasHidraulicas
IMPORTS BombaHidraulica
EXPORTS llenar()
        vaciar()
        agregar(i BombaHidraulica)
        eliminar(i BombaHidraulica)
```

```
MODULE  ControlSensoresDeProfundidad
IMPORTS SensorProfundidad
EXPORTS sensar(i SensorProfundidad) : Int
        agregar(i SensorProfundidad)
        eliminar(i SensorProfundidad)
```

```
MODULE  ControlSensoresDeCursoDeAgua
IMPORTS SensorCursoDeAgua
EXPORTS sensar(i SensorCursoDeAgua) : Curso
        agregar(i SensorCursoDeAgua)
        eliminar(i SensorCursoDeAgua)
```

```
MODULE  ControlSensoresDeLlegadaEmbarcación
IMPORTS SensorLlegadaEmbarcación
EXPORTS inicializar(i *f)
        agregar(i SensorLlegadaEmbarcación)
        eliminar(i SensorLlegadaEmbarcación)
PRIVATE llegadaDeEmbarcación(i llegadaDeEmbarcación)
```
