# Estación climatométrica

## Enunciado

Este sistema proporcionará monitorización automática de varias condiciones climatológicas.

| Debe medir                        | También calcula                   |
|-----------------------------------|-----------------------------------|
| Velocidad y dirección del viento  | Factor de enfriamiento            |
| Temperatura                       | Temperatura del punto de rocío    |
| Presión atmosférica               | Tendencia de la temperatura       |
| Humedad                           | Tendencia de la presión           |

El sistema tendrá una forma de determinar la fecha y la hora actuales, de manera que pueda informar de los valores máximos y mínimos de cualquiera de las cuatro medidas principales durante las últimas 24 horas. El sistema tendrá una pantalla que indicará continuamente todas las medidas así como la fecha y la hora. Mediante el uso de un teclado, el usuario puede dirigir al sistema para que muestre el máximo o el mínimo en las últimas 24 horas de cualquiera de las medidas principales, junto con la hora en que se dio tal valor. El sistema permitirá al usuario calibrar sus sensores respecto a valores conocidos, y ﬁjar la hora y fecha actuales.

Aplicar el patrón Command.

Use el patrón Iterator para muestrear los valores sensados.

## Documentación

| Pattern | RecorridoMuestras |
|---|---|
| **based on** | Iterator |
| **because** | - Permite recorrer las muestras de las últimas 24 h sin exponer su representación interna, y admite cambiarla (buffer circular, lista, archivo) o mantener varios recorridos simultáneos |
| **where** | Iterator **is** Iterador<br>ConcreteIterator **is** IteradorMuestras<br>Aggregate **is** Coleccion<br>ConcreteAggregate **is** HistoricoMuestras<br>CreateIterator() **is** crearIterador()<br>First() **is** primero()<br>Next() **is** siguiente()<br>IsDone() **is** terminado()<br>CurrentItem() **is** actual() |

```
MODULE  Comando
EXPORTS ejecutar()
```

```
MODULE  ComandoMostrarMaximo INHERITS FROM Comando
IMPORTS Estacion, Pantalla, Muestra
```

```
MODULE  ComandoMostrarMinimo INHERITS FROM Comando
IMPORTS Estacion, Pantalla, Muestra
```

```
MODULE  ComandoCalibrar INHERITS FROM Comando
IMPORTS Sensor
```

```
MODULE  ComandoFijarFechaHora INHERITS FROM Comando
IMPORTS RelojInterno
```

```
MODULE  Teclado
EXPORTS obtenerTecla() : Tecla
```

```
MODULE  Invocador
IMPORTS Comando
EXPORTS registrar(i Accion, i Comando)
        invocar(i Accion)
```

```
MODULE  Estacion
IMPORTS Sensor, HistoricoMuestras, Iterador, Muestra
EXPORTS registrar(i Medida, i Valor, i Hora)
        obtenerUltima(i Medida) : Muestra
        obtenerMaximo(i Medida) : Muestra
        obtenerMinimo(i Medida) : Muestra
        factorEnfriamiento() : Valor
        puntoDeRocio() : Valor
        tendenciaTemperatura() : Tendencia
        tendenciaPresion() : Tendencia
```

```
MODULE  Sensor
EXPORTS sensar() : Valor
        calibrar(i Valor)
```

```
MODULE  Muestra
EXPORTS obtenerValor() : Valor
        obtenerHora() : Hora
```

```
MODULE  Iterador
IMPORTS Muestra
EXPORTS primero()
        siguiente()
        terminado() : Bool
        actual() : Muestra
```

```
MODULE  IteradorMuestrasPorFechaHora INHERITS FROM Iterador
IMPORTS HistoricoMuestras, Muestra
```

```
MODULE  Coleccion
IMPORTS Iterador
EXPORTS crearIterador() : Iterador
```

```
MODULE  HistoricoMuestras INHERITS FROM Coleccion
IMPORTS Muestra, IteradorMuestras
EXPORTS agregar(i Muestra)
```

```
MODULE  RelojInterno
EXPORTS obtenerHora() : Hora
        obtenerDia() : Dia
        fijarFechaHora(i FechaHora)
```

```
MODULE  Pantalla
EXPORTS mostrar(i Muestra)
```

```
MODULE  Sistema
IMPORTS Teclado, Invocador,
        ComandoMostrarMaximo, ComandoMostrarMinimo, ComandoCalibrar, ComandoFijarFechaHora,
        Estacion, Sensor, RelojInterno, Pantalla
EXPORTS inicializar()
        ejecutar()
PRIVATE interpretar(i Tecla) : Accion
```
