# Estación climatométrica

## Enunciado

Este sistema proporcionará monitorización automática de varias condiciones climatológicas.

| Debe medir                        | También calcula                   |
|-----------------------------------|-----------------------------------|
| Velocidad y dirección del viento  | Factor de enfriamiento            |
| Temperatura                       | Temperatura del punto de rocío    |
| Presión atmosférica               | Tendencia de la temperatura       |
| Humedad                           | Tendencia de la presión           |

El sistema tendrá una forma de determinar la fecha y la hora actuales, de manera que pueda informar de los valores máximos y mínimos de cualquiera de las cuatro medidas principales durante las últimas 24 horas. El sistema tendrá una pantalla que indicará continuamente todas las medidas así como la fecha y la hora. Mediante el uso de un teclado, el usuario puede dirigir al sistema para que muestre el máximo o el mínimo en las últimas 24 horas de cualquiera de las medidas principales, junto con la hora en que se dio tal valor. El sistema permitirá al usuario calibrar sus sensores respecto a valores conocidos, y ﬁjar la hora y fecha actuales.

Aplicar el patrón Command.

## Los módulos 2MIL

```
MODULE  Comando
EXPORTS ejecutar()
```

```
MODULE  ComandoMostrarMaximo INHERITS FROM Comando
IMPORTS Estacion, Pantalla
```

```
MODULE  ComandoMostrarMinimo INHERITS FROM Comando
IMPORTS Estacion, Pantalla
```

```
MODULE  ComandoCalibrar INHERITS FROM Comando
IMPORTS Sensor
```

```
MODULE  ComandoFijarFechaHora INHERITS FROM Comando
IMPORTS RelojInterno
```

```
MODULE  Teclado
EXPORTS obtenerTecla() : Tecla
```

```
MODULE  Invocador
IMPORTS Comando
EXPORTS registrar(i Accion, i Comando)
        invocar(i Accion)
```

```
MODULE  Estacion
IMPORTS Sensor
EXPORTS obtenerMaximo(i Medida) : Valor
        obtenerMinimo(i Medida) : Valor
        registrar(i Medida, i Valor)
```

```
MODULE  Sensor
EXPORTS sensar() : Valor
        calibrar(i Valor)
```

```
MODULE  RelojInterno
EXPORTS obtenerHora() : Hora
        obtenerDia() : Dia
        fijarFechaHora(i FechaHora)
```

```
MODULE  Pantalla
EXPORTS mostrar(i Valor, i Hora)
```

```
MODULE  Sistema

        ejecutar()
```
