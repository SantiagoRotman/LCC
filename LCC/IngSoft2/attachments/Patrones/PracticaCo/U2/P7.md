## Enunciado

La empresa de venta por correo desea poner sus catálogos en su sitio Web. Además desea que los catálogos puedan mostrarse ordenados de diferente forma. Por ejemplo, orden alfabético de productos, de secciones de nivel 1, por precio, etc. Aplique el patrón Strategy para implementar esta funcionalidad.

## Documentación

| Pattern | OrdenamientoCatálogos |
|---|---|
| **based on** | Strategy |
| **because** | - Permite elegir en tiempo de ejecución cómo se ordena y presenta el catálogo, y agregar nuevas formas sin modificar la vista ni el control |
| **where** | Strategy **is** Orden<br>ConcreteStrategy **is** OrdenAlfabético<br>ConcreteStrategy **is** OrdenPorSeccionesDeNivel1<br>ConcreteStrategy **is** OrdenPorPrecio<br>Context **is** ControlCatálogos<br>AlgorithmInterface() **is** mostrar() |

## Modulos 2MIL

```
MODULE  GeneradorCatálogos

```
MODULE  OrdenAlfabético INHERITS FROM Orden
```

```
MODULE  OrdenPorSeccionesDeNivel1 INHERITS FROM Orden
```

```
MODULE  OrdenPorPrecio INHERITS FROM Orden
```

```
MODULE  ControlCatálogos
IMPORTS Orden, Catálogo, PestañaCatálogos
EXPORTS mostrar()
```

```
MODULE  PestañaCatálogos

```
MODULE  Catálogo

```
