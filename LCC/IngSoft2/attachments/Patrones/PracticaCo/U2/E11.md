# Control de ingreso

## Enunciado

Una aplicación debe implementar un control de ingreso (login) mediante usuario y contraseña. Ademas, se debe corroborar que el puesto de trabajo (es decir la computadora que se esta usando) esta autorizado para acceder la aplicación, que el usuario esta autorizado a usar la aplicación (mas allá de que su nombre de usuario y contraseña sean correctos o no), se debe dejar constancia de la hora de ingreso y egreso y de puesto desde donde se ingresa, etc.

1. Aplique el patrón de diseño Decorator para efectuar todos estos controles y documente adecuadamente el diseño.

2. Suponga que el administrador del sistema dispone de una pantalla de conﬁguración desde la cual puede seleccionar diferentes opciones de controles (por ejemplo, controlar usuario y contraseña y autorización del puesto; o controlar autorización del puesto y registro de ingreso y egreso).

Aplique el patrón de diseño Strategy para resolver este problema.

3. Respecto del punto anterior explique como debería ser el código para reconﬁgurar el sistema en tiempo de ejecución cada vez que el administrador selecciona una opción diferente.


## Documentación

Pattern: ConfiguraciónDeAcceso
Based on: Decorator
Where:
- Component is ControlDeIngreso
- ConcreteComponent is LogInUsuarioContraseña
- Decorator is ControlDecorador
- ConcreteDecorator is ControlPuestoDeTrabajoAutorizado
- ConcreteDecorator is ControlUsuarioAutorizado
- ConcreteDecorator is ControlBitacoraIngresoEgreso
- ConcreteDecorator is ControlBitacoraPuesto
- operation() is chequear()

Pattern: ConfiguraciónDeControles
Based on: Strategy
Where:
- Strategy is ControlDeIngreso
- ConcreteStrategy is ControlDecorador
- Context is ControlDeAcceso
- AlgorithmInterface() is chequear()
- ContextInterface() is chequeoAcceso()
